### Lean official builds

- Release builds no longer create or write `~/Library/Logs/FasterSpaces.log`, point the login agent at a log path, or show the Diagnostics window, Diagnostics menu item, or **Open log** buttons.
- Development builds keep the log and diagnostics for debugging. Existing log files are not deleted; a release build simply stops writing to them.

### Menu-bar Space strip

- New **Settings → General → Show every Space in the menu bar** option, off by default.
- It shows every Space as a clickable number next to the menu-bar icon; the current Space is highlighted, and clicking a number jumps straight to that Space.
- The existing single Space counter is disabled while the full strip is shown.
