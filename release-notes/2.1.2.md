### Dock click modifiers

- A normal Dock click still runs each app's configured action.
- **Shift-click** opens a new window; **Control-click** brings the existing
  window to the current Space.
- If the modifier's action is already the app's configured action, it toggles
  that action off. The Shift/Control flag is stripped and the Dock receives a
  regular click, so the app activates or unmasks normally.
- Shift and Control also override unlisted apps; apps set to **None** behave
  like unlisted apps for modifier clicks.
- Command and Option clicks remain native. If Shift and Control are both held,
  Control wins.
