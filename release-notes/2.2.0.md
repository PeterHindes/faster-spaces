### Check for Updates

- **Settings → General** has a new **Check for Updates** card, and **Check for Updates…** is in the menu bar and the app menu.
- It reads a small version file from the project website only when you ask. No account, identifier, or telemetry is sent, and nothing runs automatically.
- It shows your current version, whether a newer release exists, and a **Download…** button.
- The release workflow updates the feed as part of publishing a release.

### Settings in the app switcher

- Opening Settings (or onboarding/diagnostics) now switches Faster Spaces to a regular app before the window appears, so it is reachable through **Command-Tab** and the Dock while it is open.
- A normal app menu and Window menu are available while Settings is front; closing the last window returns Faster Spaces to menu-bar-only mode.
- The update check is also available from the app menu.

### Website

- The site's download counter is now read live in the browser from GitHub's public release data, with a 15-minute cache. It includes downloads from external links and does not add a background workflow.
