Built for people who live in Spaces

Everything the slide should have been.

No new muscle memory. No system hacks. Just the gesture you already use, with the delay removed.

Instant by design

The native gesture is intercepted before the Dock animates it. Faster Spaces posts the Dock's own swipe with near-zero travel and a fling velocity, so the Space changes in one frame — no slide, no blur, no lingering wallpaper pan. A compact direction HUD shows the move without covering the screen.

Follows your trackpad

Reads the current macOS Spaces finger setting and ignores the other count. A 4-finger swipe does nothing when macOS is set to 3, and vice versa.

Cross several Spaces

A long swipe keeps going. Set the distance per Space and the maximum jump, then move through a whole row of desktops in one motion.

Reverse mid-swipe

Changed your mind halfway? Swipe back without lifting your fingers. Every threshold you cross is tracked in both directions, so the Spaces retrace instead of locking you into the first direction.

Lives in the menu bar

See your current Space, jump left or right, pause the app, or open settings from a tiny menu-bar icon. Optionally show the Space counter next to it.

Quietly considerate

Launch at login, subtle haptic ticks, and an empty-desktop guard that stops macOS from yanking you to another Space a moment after you land.

Under the hood

It uses the Dock's own pipeline.

Faster Spaces does not move windows or fake Mission Control. It listens for the private Dock-swipe gesture, suppresses the animated original, and posts a complete synthetic gesture through the same path macOS uses. Mission Control, focus, wallpaper, full-screen apps and the Dock all stay in sync.

  1. 01
    Catch the gesture

    A CGEventTap watches Dock-control events before the Dock sees them. A raw-touch check keeps only the finger count macOS is configured for; vertical Mission Control swipes are never touched.

  2. 02
    Replace the travel

    The animated event is swallowed. A three-phase synthetic swipe is posted with almost no progress and a strong terminal velocity.

  3. 03
    Land instantly

    The Dock commits the switch but has no distance left to animate. On macOS 27 a serialized IOHID payload makes the synthetic gesture pass validation.

No SIP disable. No injected code. No DYLD tricks. Accessibility permission is required because macOS gates synthetic input behind it.

Direction, not drama

Know which way you moved.

A compact HUD slides two desktop tiles for a quarter of a second, showing the origin and destination without covering the screen or bringing back the native slide. During a long swipe it replays the motion for every additional Space crossed. It is purely visual, independent of the switch, and can be turned off for a hard cut.

Install in under a minute

Bring your own Spaces.

Requires macOS 13 or later. The release is Apple Silicon (arm64), built and tested on macOS 27.0.1. The distributed build is self-signed, not notarized.

1

Download & unzip

Grab the latest release, unzip it, and drag Faster Spaces.app into /Applications.

All releases →
2

Open it once

Because the build is not notarized, macOS may ask you to confirm. Right-click the app and choose Open, or clear the quarantine flag:

xattr -dr com.apple.quarantine "/Applications/Faster Spaces.app"
3

Grant Accessibility

Open the welcome window and click Grant Access…, then enable Faster Spaces in System Settings → Privacy & Security → Accessibility. Swipe normally.

Why is this needed? →

Prefer to build it yourself? The whole app is a handful of Swift files and a shell script. No Xcode project required.

git clone https://github.com/PeterHindes/faster-spaces.git && cd faster-spaces && ./scripts/build.sh

Questions

Good to know.

Why does it need Accessibility permission?

macOS only lets trusted apps replace synthetic input. Faster Spaces uses that access to read the Dock's private gesture stream and post the instant replacement. It does not read keystrokes, screen contents, or any other input.

Does it disable SIP or modify system files?

No. It does not disable SIP, inject code, or patch Dock. It uses public CGEventTap and CGEventPost APIs with a few undocumented event field constants. The only persistent change it offers is a per-user LaunchAgent for “Launch at login,” which you can turn off.

Will it work with 3 fingers and 4 fingers?

Yes, automatically. Faster Spaces intercepts the Spaces gesture the Dock already receives, so it follows whatever is configured in System Settings → Trackpad → More Gestures. There is no second setting.

What happens to Mission Control and App Exposé?

They are untouched. Only horizontal Dock-swipe gestures are intercepted; vertical swipes are passed through unchanged.

Why is the download not notarized?

Faster Spaces is an independent open-source utility. The release is self-signed so the Accessibility grant stays stable across rebuilds, but it is not signed with a paid Apple Developer ID. That is why the first launch needs a right-click → Open. The source is available if you would rather build it locally.

How do I uninstall it?

Turn off Launch at Login in settings, quit Faster Spaces, drag it from Applications to the Trash, and remove it from System Settings → Privacy & Security → Accessibility. The LaunchAgent lives at ~/Library/LaunchAgents/com.fasterplz.fasterspaces.login.plist if you need to remove it manually.

What about multiple displays?

The Dock routes a Space swipe to the display under the pointer, not the display with keyboard focus. Faster Spaces follows the same rule, so hovering a display before swiping targets that display.
